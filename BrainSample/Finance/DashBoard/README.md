## How to read these files

| Thing         | Meaning                                                             |
| ------------- | ------------------------------------------------------------------- |
| 🟢 🟡 🔴 ⚪    | fine · watch it · act now · nothing happening                        |
| `*`           | a guess about the future, not something that already happened        |
| 💵 🏦 💳       | wallet · bank account · credit card                                  |
| Category      | one word saying *what kind* of spending it was (`Food`, `Vices`, …)  |
| Transfer      | moving my own money between my accounts — never counts as spending   |
| Card purchase | counts as spending the day I buy, but only leaves the bank on the bill's due date |
